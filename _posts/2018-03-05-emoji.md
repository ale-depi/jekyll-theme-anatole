There are several Jekyll plugins available that enable emoji support. 
<!--more-->

For this project, we've chosen jemoji. Once added to the configuration, the plugin is always active and allows you to insert emojis into any post by simply typing their code. For a list of available codes, visit the page [Emoji cheat sheet](http://www.emoji-cheat-sheet.com/).

Example:

:see_no_evil: `:see_no_evil:` :hear_no_evil: `:hear_no_evil:` :speak_no_evil: `:speak_no_evil:`
